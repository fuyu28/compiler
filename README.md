# Compiler

このリポジトリは、オーム社の
[『コンパイラ 第2版』](https://www.ohmsha.co.jp/book/9784274224720/)
に掲載されているサンプルコードをベースに、宿題の内容と
`Makefile` を追加したものです。C 言語で実装された小規模な
コンパイラを手元でビルドし、入力ソースから出力ファイルを生成できます。

## 構成

コンパイラ本体は複数の C ソースファイルに分かれており、
`make` を実行すると `sc` という実行ファイルが生成されます。
`test.c` は動作確認用のサンプルとして使えます。

## 必要環境

- `gcc`
- `make`

## ビルド

以下のコマンドでコンパイラをビルドできます。

```sh
make
```

生成物を削除したい場合は、次のコマンドを実行してください。

```sh
make clean
```

## 使い方

生成された `sc` は、入力ファイルと出力ファイルを指定して実行します。

```sh
./sc <input.c> <output>
```

たとえば、同梱されている `test.c` を入力にする場合は次のように実行します。

```sh
./sc test.c test.s
```

## 補足

ビルド時には元のサンプルコードに由来する警告が表示されることがありますが、
現状の `Makefile` ではそのまま `sc` を生成できます。
